# Customer Segmentation Summary

## Objective

The objective of this phase was to identify meaningful customer groups using unsupervised machine learning techniques.

## Methodology

Customer segmentation was performed using the K-Means clustering algorithm. Before clustering, categorical variables were one-hot encoded and all features were standardized to ensure equal contribution during distance calculations.

The optimal number of clusters was explored using the Elbow Method, after which the final K-Means model was trained.

## Results

Each customer was assigned to a cluster representing a group with similar characteristics. A cluster summary was generated to analyze the average profile of each group and support the creation of business personas.

## Business Value

Customer segmentation enables the business to design personalized marketing campaigns, prioritize retention efforts, improve customer engagement, and optimize resource allocation by targeting specific customer groups instead of treating all customers identically.
